# Cybersecurity Fundamentals

These are notes written in my own words while studying cybersecurity.

## CIA Triad

- Confidentiality: Information should only be accessible to authorized people.
- Integrity: Information should remain accurate and only be changed by authorized users.
- Availability: Systems and information should be accessible when needed.

## Security Controls

Security controls are safeguards used to reduce security risks.

## PII and SPII

PII (Personally Identifiable Information) is information that can be used to identify an individual.

SPII (Sensitive Personally Identifiable Information) is sensitive PII that requires stricter handling and protection.

Examples of SPII can include:
- Bank account information
- Medical records

## SIEM

SIEM stands for Security Information and Event Management.

SIEM tools collect and analyze security logs to help analysts identify unusual activity, threats, risks, and vulnerabilities.

## IDS

IDS stands for Intrusion Detection System.

An IDS monitors systems or networks and alerts analysts to potentially malicious activity.

## Incident Response

Incident response involves following established procedures to investigate and respond to security incidents.

Example:
Alert > Investigate > Identify the problem > Respond/Remediate

## Digital Forensics

Digital forensics involves identifying, analyzing, and preserving digital evidence from computers, networks, and electronic devices.
